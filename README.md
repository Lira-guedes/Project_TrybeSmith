# TrybeSmith

<p>O projeto TrybeSmith é uma aplicação desenvolvida para praticar TypeScript, focando na construção de uma API que gerencia uma loja de itens medievais. Este projeto tem como objetivo fixar o aprendizado da sintaxe TypeScript, tipando variáveis e funções para tornar o código mais compreensível e robusto.</p>

<h3>O que foi desenvolvido?</h3>
<p>Foi desenvolvido um CRUD (Create, Read, Update e Delete) de itens medievais, no formato de uma API, utilizando TypeScript. A aplicação irá contar com endpoints que lerão e escreverão em um banco de dados usando Sequelize. Para a realização deste projeto, foi requisitado a declaração de variáveis e funções com tipagens TypeScript e a construção de uma API Node Express utilizando TypeScript</p>

<h3>Informações importantes</h3>
<ul>
  <li>Camadas do Projeto: O projeto foi desenvolvido em cima das camadas <strong>Model</strong>, <strong>Service</strong> e <strong>Controller</strong>.</li>
  <li>Endpoints da API: Foram criados endpoints que irão ler e escrever em um banco de dados MySQL através do ORM Sequelize.</li>
   <li>Não haverá front-end neste projeto</li>
  <li>A API foi completamente desenvolvida dentro do diretório <code>./src</code>.</li>
</ul>

<h3>Habilidades para o Projeto</h3>
<ul>
    <li>Introdução ao TypeScript.</li>
    <li>Tipagem estática e generics.</li>
    <li>Express com TypeScript.</li>
</ul>
